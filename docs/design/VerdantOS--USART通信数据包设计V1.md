# 数据包结构
固定包长，含包头包尾
## 需要的内容及需要的位数

指令类型（自动管理、手动管理）  1bit
控制的设备（设备号）   6bits
操作类型（打开/关闭）  1bit
操作参数：
周期  uint8_t
时长 uint8_t
重复次数 4bits
档位 4bits
加上包头包尾，共6个字节可以解决

## 数据包格式
包头---指令（指令类型|操作类型|设备号（6bits））--周期--时长--重复次数及档位--包尾

其中：
指令最高位为指令类型
指令类型：1--自动管理    0--手动管理
操作类型：1--开启          0--关闭

重复次数及档位里
高4位位重复次数，低4位为档位

比如：11000001  00000010  00000011  00110001
代表：设备ID为000001的设备开启自动养护，参数是：周期为2，时长为3，重复3次，档位为1
