# 概览
采用**固定长度 6 字节数据帧**，用于 Qt 上位机与 STM32 控制端之间的指令通信。

```
┌──────┬────────────┬──────┬──────┬────────────┬──────┐
│ 包头 │    指令    │ 周期 │ 时长 │ 重复次数/档位 │ 包尾 │
│ 1 Byte│  1 Byte   │1 Byte│1 Byte│   1 Byte   │1 Byte│
└──────┴────────────┴──────┴──────┴────────────┴──────┘
```

总长度：

```
1 + 1 + 1 + 1 + 1 + 1 = 6 Bytes
```

其中，**指令字节**和**重复次数/档位字节**采用位域设计，以减少通信数据量。

#  1. 指令字节

```
Bit 7        Bit 6 ~ Bit 1       Bit 0
┌─────┬──────────────────────┬─────┐
│ 模式 │       设备 ID        │操作 │
│ 1 bit│       6 bits        │1 bit│
└─────┴──────────────────────┴─────┘
```

|位|字段|长度|含义|
|---|---|---|---|
|Bit 7|控制模式|1 bit|`0`：手动管理；`1`：自动管理|
|Bit 6~1|设备 ID|6 bits|标识目标设备，范围 `0~63`|
|Bit 0|操作类型|1 bit|`0`：关闭/停止；`1`：开启/启动|

因此：

```
指令字节 = (控制模式 << 7)
         | (设备ID << 1)
         | 操作类型
```

#  2. 周期

```
Byte 2：周期
```

采用 `uint8_t` 表示自动管理模式下的执行周期。

#  3. 时长

```
Byte 3：时长
```

采用 `uint8_t` 表示单次设备运行持续时间。

#  4. 重复次数与档位

```
Bit 7 ~ Bit 4        Bit 3 ~ Bit 0
┌──────────────────┬────────────────┐
│     重复次数      │      档位      │
│      4 bits      │     4 bits     │
└──────────────────┴────────────────┘
```

|位|字段|长度|范围|
|---|---|---|---|
|Bit 7~4|重复次数|4 bits|`0~15`|
|Bit 3~0|档位|4 bits|`0~15`|

对应：

```
重复次数/档位 = (重复次数 << 4) | 档位
```

#  5. 完整数据帧

```
Byte 0       Byte 1       Byte 2       Byte 3       Byte 4       Byte 5
┌────────┬────────────┬──────────┬──────────┬────────────┬────────┐
│  包头  │    指令    │   周期   │   时长   │ 重复次数/档位 │  包尾  │
└────────┴────────────┴──────────┴──────────┴────────────┴────────┘
   1 B         1 B          1 B        1 B          1 B         1 B
```

例如：

```
11000001  00000010  00000011  00110001  XXXXXXXX  XXXXXXXX
```

其中第一个字节：

```
11000001
││     │
│└─────┼── 设备 ID = 000001 = 1
│      └── 操作 = 1，启动
└───────── 模式 = 1，自动管理
```

因此该指令表示：

> **对设备 1 执行自动管理模式下的启动操作。**
